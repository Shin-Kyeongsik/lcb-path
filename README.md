# lcb-path — 리눅스 명령어 기초 실습 자료 1 (경로와 이동)

「리눅스 명령어 기초 (Linux Command Basics)」 Ch.3~Ch.7에서 쓰는 실습 자료입니다.

## 받는 방법
1. 이 페이지의 **Code ▸ Download ZIP**을 눌러 `lcb-path-main.zip`을 받습니다.
2. 압축을 풀고, 풀린 `lcb-path-main` 폴더를 **바탕화면**으로 옮깁니다.
   - Windows에서는 `lcb-path-main` 안에 `lcb-path-main`이 한 번 더 생길 수 있습니다. **안쪽 폴더**를 바탕화면으로 옮기세요.
3. 바탕화면에 `lcb-path-main` 폴더가 있으면 준비 끝입니다.

## 폴더 구조
```
lcb-path-main/
├── README.md
├── documents/
│   ├── report.txt
│   ├── my notes/
│   │   └── todo.txt
│   ├── study/
│   │   ├── linux/
│   │   │   └── commands.txt
│   │   └── python/
│   │       └── basics.txt
│   ├── study notes/
│   │   └── summary.txt
│   └── studio/
│       └── ideas.txt
├── pictures/
│   ├── profile.png
│   └── travel/
│       ├── busan/
│       │   └── market.jpg
│       └── jeju/
│           └── beach.jpg
└── downloads/
    ├── data.csv
    └── manual.pdf
```

- `my notes`, `study notes`처럼 **이름에 띄어쓰기가 있는 폴더**가 있습니다 (Ch.5).
- `study`, `study notes`, `studio`는 **앞부분이 같은 이름**입니다 (Ch.7 자동 완성).
- 이 폴더 안의 파일은 지우거나 옮기지 않습니다. 만들고 지우는 연습은 바탕화면에 따로 만든 연습용 폴더에서 합니다 (Ch.8).
